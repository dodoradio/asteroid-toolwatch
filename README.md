# Asteroid Toolwatch
An app to display multiple sensors (currently compass and barometer) for AsteroidOS.

This extends and replaces the asteroid-compass app.

## Dependencies
* [qml-asteroid](https://github.com/AsteroidOS/qml-asteroid)
